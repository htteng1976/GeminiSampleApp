# AGENTS

## Commit Message Convention

All commits created by Codex should use this format:

```
[Codex][MODEL_NAME] <type>: <summary>
```

Example:

```
[Codex][GPT-5.2-Codex] test: strengthen App greeting assertions
```

Notes:
- `Codex` stays constant.
- `MODEL_NAME` should reflect the model currently in use.
- `<type>` should be a short, conventional category such as `feat`, `fix`, `docs`, `test`, `chore`.
